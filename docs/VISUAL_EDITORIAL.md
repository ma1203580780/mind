# 视觉与素材编辑规范

## 2026-10-02 设计
浅纸底、石墨正文、低饱和强调色。手机端两列，自然高度卡片；桌面三列。首页融合一手资料摘读和明确标注的示例笔记，支持分类切换。归档、主题、搜索使用同一套字级与卡片间距。新闻的紧凑模式在手机上同样保留两列，收起图片。

正文、音视频播放器保持单列。留白服务于阅读，不设置没有内容作用的大幅装饰画、唱片或封面。交互使用轻微位移、阴影和清晰焦点态，尊重 reduced-motion。

## 素材
- 一手图指原作者/官方发布页中的实图、产品界面、图表或文档截图，不意味着自由版权。
- 只能用于与图中内容直接相关的条目，不把通用品牌图、栏目 banner 当内容。
- 来源名与原文链接可见，alt 描述图中内容，不把编辑解读冒充原作者观点。
- 文章封面 schema 必须同时填写 src、alt、sourceUrl、sourceName；添加前人工核对关联关系和使用条件。
- 没有合适原图就不配图。图片加载失败回到文字内容，不补虚构插画。
- 目前四篇文章仍是示例稿，不伪装成作者已完成的真实研究。原有字幕概览视频保留为明确标注的示例内容，不当一手影像使用。

## 验收
手机端两列；标题无裁切；无横向溢出；读/听/看和原始出处独立可点击；搜索与过滤不改变卡片规范；深色与减弱动效可用。统计配置、隐私开关及新闻更新机制保持有效。
