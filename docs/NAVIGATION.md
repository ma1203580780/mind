# 全站导航与页面生命周期

- 一级固定为资讯、博客、项目、发现、搜索。首页即资讯「精选」，复用资讯卡片与内容网格，保留最近文章，个人介绍集中在发现页；品牌链接回首页。订阅下沉到发现页和页脚。
- 二级：资讯的精选与七个分类；博客下的全部文章与 AI 工程、产品与交互、独立创造、思考与成长四个分类；`/archive/` 按最新文章排列，年份归档为下层入口。项目页展示 mind、看云与慕课网 SRE 课程三个项目，以状态、短简介和主入口组成悬浮展台；发现承接近况、共创、连接与值得关注的信息源。
- 当前 Tab 已说明页面身份时，不再用同名大标题重复占据正文。保留一个语义 h1（必要时使用 sr-only）；内容标题必须增加信息，文章真实标题仍显示。不要增加解释导航的宣传式首屏。
- 发现页顶部用紧凑介绍区承接一句个人介绍、三个 Focus 方向及「关于我」「关于站点」箭头链接，不显示重复的「发现」大标题。Focus 可打开对应的开放问题；「保持连接」专注 RSS、GitHub、交流反馈。页脚保留居中的站点 / 关注 / 关于三组链接。
- 日期属于收录过滤器，不占一级导航。桌面右侧，手机分类下方横向展示；切日期保持语言和分类，切分类保持日期和语言。
- 顶栏在所有页面采用相同容器、网格、字号与高度，独立于内容宽度。桌面 60px，手机 104px；滚动条预留空间避免水平位移。
- 使用 Astro ClientRouter 和 transition:persist 保留同一个顶栏 DOM；停用整页快照变形，切换时让内容模块轻微上浮并渐显，当前项下划线在同一个顶栏内连续移动。
- 页面脚本使用 onPageLoad 注册。每次 astro:before-swap 中止页面级监听、计时器、动画、观察器和进行中的索引请求。禁止直接在模块顶层仅查询一次可替换的 DOM。
- history.replaceState 必须保留 history.state，避免破坏路由后退与滚动状态。
- JavaScript 不可用时，链接仍可按普通静态站点访问。

验收重点：主/二级导航反复往返、日期与分类交叉筛选、浏览器前进后退、搜索范围、筛选及后退恢复、阅读弹窗、播放实验、文章阅读方式切换。

- 搜索只包含博客、资讯、项目，结果按类型独立分区。空状态只保留居中的输入框与 SVG 提交图标，不再显示重复标题、示例词与分类按钮；结果面板提供全部 / 博客 / 资讯 / 项目切换，kind 查询参数保存当前类型，资讯范围保留语言与分类筛选。完整页脚保持在一屏内，长结果独立滚动。空状态与结果状态以同一组可插值网格轨道衔接，输入、清空、快速反向输入均保持连续；清空淡出期间结果面板立即退出键盘交互。
- 书架及收藏入口已移除。博客使用紧凑双列/三列卡片，标签可点。
- 只保留博客 rss.xml 和资讯 news/rss.xml 两个订阅。页面 head 声明 RSS 自动发现。
- 项目的 GitHub 数据每次发布从官方 API 刷新，失败保留带更新时间的快照；只允许 ma1203580780/mind。看云指标由站长提供。

- 项目页以原生 SVG 表现轨道球体、悬浮文档与可靠性屏幕，背景采用静态光晕、轨道细线和透视网格。桌面三列、平板双列并横向展示课程、手机单列；不显示重复页标题、分组标题、进展段落和仓库统计。保留 mind / kancloud / sre-course 锚点供搜索与开放问题跳转。

- 全站动效由 `src/styles/motion.css` 与 `src/scripts/motion.ts` 统一：页面模块一次性渐显、卡片轻抬、导航下划线滑动、阅读弹窗双向开合、原生 details 高度过渡。背景不循环漂移，不加阻塞导航的退场等待。减少动态效果时立即切换；页面离开时取消所有动画、观察器与待清空计时器。
