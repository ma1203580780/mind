# 全站导航与页面生命周期

- 一级：资讯、博客、作品、搜索。首页直接展示资讯候选；品牌链接回首页。
- 二级：资讯的精选与七个分类；博客下的全部文章与三个持续专题。作品只展示 mind 仓库和看云。订阅、关于、隐私、数据页共用站点辅助导航。
- 列表不再使用宣传式首屏。保留一个语义 h1（必要时仅对辅助技术可见）；文章真实标题仍显示。
- 日期属于收录过滤器，不占一级导航。桌面右侧，手机分类下方横向展示；切日期保持语言和分类，切分类保持日期和语言。
- 顶栏在所有页面采用相同容器、网格、字号与高度，独立于内容宽度。桌面 72px，手机 108px；滚动条预留空间避免水平位移。
- 使用 Astro ClientRouter 和 transition:persist 保留同一个顶栏 DOM；禁用页面淡入淡出，切换时更新活动项。
- 页面脚本使用 onPageLoad 注册。每次 astro:before-swap 中止页面级监听、计时器、动画、观察器和进行中的索引请求。禁止直接在模块顶层仅查询一次可替换的 DOM。
- history.replaceState 必须保留 history.state，避免破坏路由后退与滚动状态。
- JavaScript 不可用时，链接仍可按普通静态站点访问。

验收重点：主/二级导航反复往返、日期与分类交叉筛选、浏览器前进后退、搜索范围、筛选及后退恢复、阅读弹窗、播放实验、文章阅读方式切换。

- 搜索包含博客、专题、资讯、作品。默认空状态提供示例词，资讯范围才显示语言与分类筛选，不在资讯页重复放搜索框。
- 书架及收藏入口已移除。博客使用紧凑双列/三列卡片，标签可点。
- 全站 RSS 为 feed.xml，博客 RSS 保持 rss.xml，新闻与候选继续独立订阅。页面 head 声明 RSS 自动发现。
- 作品的 GitHub 数据每次发布从官方 API 刷新，失败保留带更新时间的快照；只允许 ma1203580780/mind。看云指标由站长提供。
