# 搜索页：泳池水面与往返动效

参考：[Design Spells — Interactive rubber duck in Pool](https://designspells.com/spells/interactive-rubber-duck-in-pool)。

仅搜索页使用泳池背景。提取蓝色水面、折射光网、小黄鸭和触碰涟漪的视觉方向，以本地 SVG、CSS 和原创 WebGL shader 实现，不载入外部视频、图片、字体或品牌文字。

## 交互

- 空搜索在可用内容区中央；输入关键词后，搜索框用 680ms 的缓出动效上移，结果稍后显现。清空关键词时返回中央。
- 往返过程中再次输入或清空，会从搜索框当前可见位置反转，不回跳到上一帧的起点。已有关键词的书签直接进入结果布局。
- 水面缓慢流动。鼠标移动和轻触空白水面可触发涟漪，输入框、按钮和链接保留原生操作。
- 深色模式呈现夜间水面。背景没有标题、说明或 Pool 的标识。
- 其他栏目继续使用共享天空；搜索页仅隐藏并暂停它，离开搜索后恢复。

## 资源与回退

- 搜索框使用 FLIP 位置补间，只在切换布局时测量位置，通过 transform 动画移动；避免逐帧改变整个结果区布局。
- 水面最多 30fps、约 90 万绘制像素、8 个同时存在的涟漪；隐藏页面、离开视口或启用“减少动态效果”时停止循环。
- WebGL 不可用或丢失时显示本地 SVG 水面；恢复后重新建立绘制资源。离开页面清除绘制、监听器和观察器。
- “减少动态效果”保留静态水面，搜索布局直接切换。

## 验证边界

构建与自动测试覆盖搜索框上下切换、快速反转、错误重试、动态偏好、涟漪缓冲、资源回收、WebGL 失败回退以及页面结构。本次浏览器访问被管理策略阻止，未进行真实浏览器视觉验收；模拟测试不能证明 shader 的实际渲染效果。
