# 全站视觉规划：蓝天、暖光与安静的内容

规划日期：2026-10-04。用户已认可三篇详情页和博客目录的蓝天背景，本轮将同一视觉语言覆盖全部现有页面。先完成此规划和本地设计板，再实现共享组件与页面适配。

后续确认：五个一级入口统一采用博客目录的完整天空背景，页面内部仍保留各自布局。本文早期规划与首轮结果保留作记录；本轮发布以末尾更新为准。

## 一致性来自哪里

共用天空蓝 #c5eafc、湖蓝 #0969a2、墨蓝 #173e5a、奶油黄 #fbf4d0；薄荷仅作小面积辅助。页面底色偏蓝白，正文仍用容易阅读的中性深色。没有玫红、蓝紫或灰绿主调。

标题不超过 26px。阅读正文 16px，其他内容以 14/16/18/22/26px 为主要层级，辅助日期等可用 12px。信息量大的资讯保留浏览效率，不放营销式大标题。普通段落不装进卡片；卡片、提示和控件才有圆角与阴影。

统一顶部导航、主题按钮和页脚。页头以近白透明表面承接不同背景；当前菜单用淡蓝而非黑块。焦点和选中状态共用湖蓝。

## 六类场景与七种背景

| 页面角色 | 页面 | 背景处理 | 内容与布局 |
| --- | --- | --- | --- |
| 阅读 | 三篇已认可文章 | 现有开阔蓝天、四层轻薄云；不重画已认可构图 | 文章主栏与侧边目录、正常字号、白底阅读 |
| 阅读 | 其余现有文章、资讯详情 | 浅蓝远景，轻弧线靠两侧，静止 | 保持真实文章和来源结构，标题与正文间留足空间 |
| 浏览 | 博客目录 | 已认可蓝天保留 | 按年份、白色圆角卡片、三层轻阴影 |
| 浏览 | 标签、专题、日期归档 | 更浅的远景天光，不重复完整云层 | 简短可见标题、少量计数、紧凑列表或卡片 |
| 资讯 | 首页、精选、日刊及筛选分页 | 薄雾偏蓝，右上少量暖光，短背景 | 轻量栏头，资讯列表与筛选优先；资讯功能完整保留 |
| 创作 | 项目、项目动态 | 蓝绿水光与暖白弧面，静止 | 原生 SVG 项目物件继续保留，移除网格地板和紫色光团；三张作品各有蓝/薄荷/奶油底色 |
| 连接 | 发现、关于我、一起做 | 奶油暖阳与蓝色边缘，静止 | 更有人情味的介绍；正文、项目列表和联系入口保留 |
| 工具 | 搜索、数据、信息源 | 接近白纸的极浅蓝雾，静止 | 输入与数据优先，表单使用清楚的蓝色焦点和轻阴影 |
| 说明 | 订阅、隐私、关于本站、404 | 暖白纸面与角落光晕，静止 | 短标题和正文，RSS、偏好开关与返回入口容易操作 |

差异是有限的。不会给每条资讯重新抽签换颜色，也不按文章标题生成装饰；同一类型所有动态路由共享构图。每页最多一个主背景。背景仅使用 SVG/CSS，不增加位图、外部字体、动画库或素材请求。

## 组件和页面覆盖方式

1. `site-presentation.mjs` 明确映射路由到页面角色和背景。子路径、编码标签、部署前缀都规范化处理。
2. `PageBackdrop.astro` 仅呈现装饰，不增加标题或地标，不接管点击。现有三篇阅读 Hero 和博客目录有自己的背景时不额外叠加。
3. `site-theme.css` 共用色彩、控件、表面、字号和导航；`site-scenes.css` 负责不同背景与少量场景适配。
4. 页面原有搜索、筛选、模态阅读、订阅、隐私和文章交互保持真实内容与行为。
5. 项目和发现页移除旧的背景装饰，避免两套视觉并存。

## 动效约束

只有已认可的云层缓慢飘动。其他背景保持静止。鼠标悬停最多移动 2px；没有页面入场长动画、光标追踪、粒子或正文视差。离屏、后台和减少动态偏好继续控制云层。

## 验证计划

构建全部现有静态路由，检查每页是否有且只有一个主背景、共享页头、正确主题角色和有效本地资源；覆盖资讯深路由、博客、项目、发现、工具和说明页。运行与导航、文章、搜索数据和项目关联有关的回归检查。

浏览器策略当前不可用，禁止借其他浏览器或渲染方式绕过。本轮用设计板、源码结构、构建与 HTTP 检查验证可交付性，视觉效果和真实点击未验收时如实注明。只在本地实现，不推送或发布。

## 实现与验证结果

- 实现了 7 种背景：sky / horizon / air / tide / dawn / mist / paper；对应阅读、浏览、资讯、创作、连接、工具和说明 7 个角色。设计板为了直观比较将薄雾与白纸归为一组，共 6 张场景示意。
- 690 页全部构建通过；其中资讯 317 页、阅读详情 341 页、浏览 20 页、创作 2 页、连接 3 页、工具 3 页、说明 4 页。
- 46 项自动检查通过，包括全部生成页的共享导航、唯一主标题、单一背景、背景不可交互、本地资源有效性与原有数据/隐私/订阅检查。
- 20 个代表性路径、19 份样式/脚本资源和本地设计板返回正常；新闻详情与编码标签等深路由也包含在静态覆盖中。
- 取消自动整段入场动画和旧的移动下划线；保留用户操作反馈、模态打开关闭、减少动态偏好和已认可的慢移云层。
- Markdown、历史资讯数据、订阅地址与项目链接没有改动。没有新增外部字体、位图或动画库。
- 暗色样式与窄屏规则已实现；浏览器策略仍不可用，视觉效果、真实触控、模态操作和搜索滚动尚未在浏览器中验收。静态检查不代表视觉验收。

- 生产构建 703 页通过；52 项 Node 检查与 11 项 Python 资讯检查通过。五个一级入口 HTTP 检查通过，生成的天空与样式一致。
- 新增验证覆盖五页共享背景、连续切换时动画进度、观察器不重复注册、后台暂停、离开与重新进入后的清理。验证使用源码与模拟环境，不代表浏览器视觉验收。
- 浏览器管理策略仍不可用；真实切换的视觉效果未在浏览器中验收。没有使用其他浏览器或渲染方式绕过限制。
