# 搜索与全站动效验收

日期：2026-10-04。发布基线：`9fc1a58d2b9411a2af2446dd469747f1cbfabb92`。

## 目标

- 搜索空状态居中；输入后平滑上移，清空后平滑回中；快速反向操作不跳动、不清掉新结果。
- 资讯、博客、项目、发现与一起做使用统一、克制的入场和交互节奏。
- 保留搜索一屏布局、完整页脚、独立结果滚动、主题和路由状态。
- 支持减少动态效果，页面离开后不留下动画、观察器和待执行的清空动作。

## 原因与实现

旧搜索布局直接切换 `justify-content:center/flex-start`，浏览器无法插值，结果区又即时删除，因此输入与清空都会跳位。

现在同一个输入框始终位于三行网格的中间轨道，上下空间从 `1fr/1fr` 连续变为 `0fr/2fr`，640ms 内完成可逆过渡。结果面板延后渐显、清空时短暂淡出；淡出期间立即 `inert`，避免隐藏结果继续接收键盘焦点。结果清理计时器会在下一次输入或离页时取消。索引失败时重试入口仍可操作。

新增 `motion.ts` 与 `motion.css` 管理有限时长的页面模块渐显、轻抬、导航下划线滑动、卡片反馈、details 高度开合和阅读弹窗退场。保持顶栏 DOM，继续跳过整页快照，避免长页面拉伸。装饰背景没有循环动画。减少动态效果时不创建 Web Animations 效果，运行中更改偏好也会取消动画。

主要文件：`src/pages/search.astro`、`src/scripts/search.ts`、`src/styles/explore.css`、`src/scripts/motion.ts`、`src/styles/motion.css`、`src/layouts/Base.astro`、`src/components/NewsEdition.astro`。导航规范已同步。

## 边界

动画不延迟导航、不阻止输入，不改变链接与内容顺序。浏览器不执行动画时直接使用最终静态布局。此次仅发布动效相关文件，不包含本地文章草稿及阅读套件的未发布修改。
