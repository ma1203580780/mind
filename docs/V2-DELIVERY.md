# mind V2.0 交付与浏览器验收

## 目标与实现

- 五项一级导航：资讯 / 博客 / 项目 / 发现 / 搜索。订阅下沉，选中态使用细线。
- 首页保留资讯主体，新增不超过 160px 的个人近况，以及排除示例稿的最近文章列表。
- `/discover/`：认识我、最近在做、持续关注、和我交流、一起做、我关注的人。
- `/build/`：三个开放问题、正在构建的项目、四种合作方式。
- `/lab/`：项目分组、状态、当前进展、技术栈与 GitHub 快照数据。
- 文章结尾增加带文章上下文的讨论入口、发现入口、继续阅读。没有其他正式文章时展示持续专题。
- 搜索保留 `kind=work` 兼容旧链接，显示“项目”，共用 projects 数据并跳到站内项目详情。
- Footer 分为站点 / 关注 / 关于；新增 About Me，原采集与示例内容说明保留在 `/about-site/`。
- 新增四份 JSON 配置、页面与点击事件白名单，保持现有统计退出机制。

## 发现的问题与修复

1. 构建时两个已有本地草稿引用的图片缺失。从工作区 `drafts/assets` 复制原图至 `src/content/assets`；不改草稿状态、不发布草稿。
2. 当前只有一篇非示例的正式文章，“继续阅读”按文章过滤后为空。没有正式相关文章时，回退为明确标注的持续专题；首页只展示现有的一篇，后续自然扩展至三篇。
3. 项目搜索原来全部按外部链接打开。改为按实际 URL 判断，站内项目在当前页打开，保留外部链接保护。
4. 浏览器原生页面快照在长短页面切换时出现拉伸、局部空白与超时。保留 Astro 客户端导航和持久顶栏，跳过原生快照动画，并处理主动取消动画的 ready Promise。最终截图正常。
