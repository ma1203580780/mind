# 发现页背景变更与验证

## 目标
仅给发现页加入参考图的粉、黄、浅绿颗粒流动背景，不加入参考图的文字，保留全部原有内容、链接和布局。

## 实现
- `src/components/DiscoveryBackground.astro`：固定全屏、无指针事件的装饰层；原创 WebGL 色带与颗粒，不引用外站图片或视频。
- `src/pages/discover.astro`：仅新增背景组件导入和调用。
- 30 fps、限制画布分辨率，后台暂停；减少动态效果偏好下静止；离页销毁资源；WebGL 不可用时保留静态渐变。暗色模式降低背景亮度。
