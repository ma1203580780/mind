# 三篇文章的练习材料

这些文件全部是**自造、可公开的教学数据**，没有公司信息、真实用户历史或真实模型运行成绩。它们用于构造可检查的问题，不用于证明某种 Agent 更好。

| 文件 | 用途 | 不覆盖什么 |
| --- | --- | --- |
| [rag-fixture.json](rag-fixture.json) | 8 条笔记、3 份操作材料和 6 类题，检查版本、覆盖与去重 | 主题已给定，不测语义分类；样本很小，不估计总体准确率 |
| [memory-events.json](memory-events.json) | 重放更新、例外、撤销、迟到写入与重新建立偏好 | 操作已标注，不测自然语言理解；不实现物理删除 |
| [cost-ledger.csv](cost-ledger.csv) | 同一百题的 A/B 任务级总费用与验收数，共 200 行 | 均摊费用是人为构造，不是逐调用账单，也不反映费用分布 |
| [cost-scenarios.json](cost-scenarios.json) | 验证混淆、昂贵尾部与边际预算的假设 | 回退全对等强假设需要自行实测，不能当现实前提 |
| [reference_checks.py](reference_checks.py) | 用 Python 标准库重算文章中的数字与状态 | 不调用任何 LLM；通过只说明演算内部一致 |
| [reference-results.json](reference-results.json) | 本次实际运行脚本输出 | 不是 Agent benchmark |

## 怎样使用

在这个目录运行 `python3 reference_checks.py`，不需要安装第三方库、API key 或联网。

若要评估真实系统，给系统提供语料和问题，**不要把预期答案与未来事件送进去**。保留实际输入、输出、调用记录和验收证据；使用各文章给出的对照设置。记忆题按时间逐项送入，RAG 题另加相同含义的改写和新材料。

## 三个可以直接动手的改动

1. RAG：复制一条记录但保留相同对象 ID，观察统计是否错误增加；加入一个更高版本，检查统计与证据是否更新。
2. 记忆：将临时例外换到另一任务，观察默认是否被污染；在撤销后重放迟到摘要，检查旧偏好是否恢复。
3. 成本：调整错误发现率、误退率和回退成功率，再算真实通过数。附带脚本为方便核对正文，明确断言回退全对；若改变该假设，需要同步扩展回退后仍失败的计算，不能只删断言。

这些是起步练习。真正有价值的下一步，是将自己遇到的失败做成去敏测试题，在未参与调参的新任务上复测。
